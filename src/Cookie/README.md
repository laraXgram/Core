# LaraGram Cookie

The LaraGram Cookie component creates, queues and encrypts the cookies of HTTP responses.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/cookie
```

## Documentation

Documentation for the Cookie component can be found on the [LaraGram website](https://laraxgram.github.io/v4/http-responses).
