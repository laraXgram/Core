# LaraGram Request

The LaraGram Request component is the Telegram Bot API layer: it reads incoming updates and calls the API methods.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/request
```

## Documentation

Documentation for the Request component can be found on the [LaraGram website](https://laraxgram.github.io/v4/requests).
