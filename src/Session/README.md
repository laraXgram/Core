# LaraGram Session

The LaraGram Session component provides sessions with multiple storage drivers.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/session
```

## Documentation

Documentation for the Session component can be found on the [LaraGram website](https://laraxgram.github.io/v4/session).
