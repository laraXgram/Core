# LaraGram Concurrency

The LaraGram Concurrency component runs closures concurrently in child PHP processes.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/concurrency
```

## Documentation

Documentation for the Concurrency component can be found on the [LaraGram website](https://laraxgram.github.io/v4/concurrency).
