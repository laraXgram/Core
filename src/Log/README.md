# LaraGram Log

The LaraGram Log component provides logging with multiple channels and shared context.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/log
```

## Documentation

Documentation for the Log component can be found on the [LaraGram website](https://laraxgram.github.io/v4/logging).
