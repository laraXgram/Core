# LaraGram Routing

The LaraGram Routing component routes HTTP requests for web pages, webhooks and Mini App back-ends.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/routing
```

## Documentation

Documentation for the Routing component can be found on the [LaraGram website](https://laraxgram.github.io/v4/routing).
