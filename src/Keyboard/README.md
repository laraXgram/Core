# LaraGram Keyboard

The LaraGram Keyboard component is a fluent builder for Telegram reply and inline keyboards.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/keyboard
```

## Documentation

Documentation for the Keyboard component can be found on the [LaraGram website](https://laraxgram.github.io/v4/keyboards).
