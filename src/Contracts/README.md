# LaraGram Contracts

The LaraGram Contracts component contains the interfaces that define the core services of LaraGram.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/contracts
```

## Documentation

Documentation for the Contracts component can be found on the [LaraGram website](https://laraxgram.github.io/v4/contracts).
