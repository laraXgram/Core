# LaraGram Support

The LaraGram Support component contains the support classes of LaraGram: strings, numbers, facades, service providers and helpers.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/support
```

## Documentation

Documentation for the Support component can be found on the [LaraGram website](https://laraxgram.github.io/v4/helpers).
