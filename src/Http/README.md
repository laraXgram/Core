# LaraGram Http

The LaraGram Http component provides HTTP requests, responses, API resources and the HTTP client.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/http
```

## Documentation

Documentation for the Http component can be found on the [LaraGram website](https://laraxgram.github.io/v4/http-requests).
