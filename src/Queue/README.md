# LaraGram Queue

The LaraGram Queue component processes jobs in the background over many queue back-ends.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/queue
```

## Documentation

Documentation for the Queue component can be found on the [LaraGram website](https://laraxgram.github.io/v4/queues).
