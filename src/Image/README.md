# LaraGram Image

The LaraGram Image component provides a fluent API for image manipulation.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/image
```

## Documentation

Documentation for the Image component can be found on the [LaraGram website](https://laraxgram.github.io/v4/images).
