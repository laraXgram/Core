# LaraGram Encryption

The LaraGram Encryption component provides simple, secure AES encryption.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/encryption
```

## Documentation

Documentation for the Encryption component can be found on the [LaraGram website](https://laraxgram.github.io/v4/encryption).
