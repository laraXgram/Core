# LaraGram Pagination

The LaraGram Pagination component paginates query results and collections.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/pagination
```

## Documentation

Documentation for the Pagination component can be found on the [LaraGram website](https://laraxgram.github.io/v4/pagination).
