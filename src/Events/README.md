# LaraGram Events

The LaraGram Events component is an event dispatcher with support for queued listeners.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/events
```

## Documentation

Documentation for the Events component can be found on the [LaraGram website](https://laraxgram.github.io/v4/events).
