# LaraGram Bus

The LaraGram Bus component dispatches commands and jobs, including job chains and batches.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/bus
```

## Documentation

Documentation for the Bus component can be found on the [LaraGram website](https://laraxgram.github.io/v4/queues).
