# LaraGram Broadcasting

The LaraGram Broadcasting component broadcasts events to channels, and messages to Telegram audiences.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/broadcasting
```

## Documentation

Documentation for the Broadcasting component can be found on the [LaraGram website](https://laraxgram.github.io/v4/broadcasting).
