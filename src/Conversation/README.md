# LaraGram Conversation

The LaraGram Conversation component runs multi-step conversations that collect and validate answers from Telegram users.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/conversation
```

## Documentation

Documentation for the Conversation component can be found on the [LaraGram website](https://laraxgram.github.io/v4/conversations).
