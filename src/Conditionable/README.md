# LaraGram Conditionable

The LaraGram Conditionable component provides the `when` and `unless` methods for fluent, conditional method chains.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/conditionable
```

## Documentation

Documentation for LaraGram can be found on the [LaraGram website](https://laraxgram.github.io/v4/installation).
