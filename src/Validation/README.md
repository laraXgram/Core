# LaraGram Validation

The LaraGram Validation component validates data with many built-in rules.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/validation
```

## Documentation

Documentation for the Validation component can be found on the [LaraGram website](https://laraxgram.github.io/v4/validation).
