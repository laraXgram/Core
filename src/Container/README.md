# LaraGram Container

The LaraGram Container component is a powerful dependency injection container.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/container
```

## Documentation

Documentation for the Container component can be found on the [LaraGram website](https://laraxgram.github.io/v4/container).
