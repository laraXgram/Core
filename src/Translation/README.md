# LaraGram Translation

The LaraGram Translation component localizes messages into multiple languages.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/translation
```

## Documentation

Documentation for the Translation component can be found on the [LaraGram website](https://laraxgram.github.io/v4/localization).
