# LaraGram View

The LaraGram View component renders Blade views for HTML pages.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/view
```

## Documentation

Documentation for the View component can be found on the [LaraGram website](https://laraxgram.github.io/v4/views).
