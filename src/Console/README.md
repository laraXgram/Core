# LaraGram Console

The LaraGram Console component powers the Commander console: commands, prompts, scheduling and process handling.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/console
```

## Documentation

Documentation for the Console component can be found on the [LaraGram website](https://laraxgram.github.io/v4/commander).
