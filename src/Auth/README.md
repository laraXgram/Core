# LaraGram Auth

The LaraGram Auth component provides authentication and authorization for bots and web routes: guards, user providers, gates and policies.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/auth
```

## Documentation

Documentation for the Auth component can be found on the [LaraGram website](https://laraxgram.github.io/v4/authentication).
