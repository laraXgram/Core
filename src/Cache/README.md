# LaraGram Cache

The LaraGram Cache component provides a unified API over many cache back-ends, such as files, databases, Redis and Memcached.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/cache
```

## Documentation

Documentation for the Cache component can be found on the [LaraGram website](https://laraxgram.github.io/v4/cache).
