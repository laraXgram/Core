# LaraGram Template

The LaraGram Template component is the Temple8 templating engine that composes Telegram messages.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/template
```

## Documentation

Documentation for the Template component can be found on the [LaraGram website](https://laraxgram.github.io/v4/temple8).
