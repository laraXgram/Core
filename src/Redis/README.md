# LaraGram Redis

The LaraGram Redis component connects to Redis through PhpRedis or Predis.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/redis
```

## Documentation

Documentation for the Redis component can be found on the [LaraGram website](https://laraxgram.github.io/v4/redis).
