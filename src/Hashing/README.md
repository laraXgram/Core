# LaraGram Hashing

The LaraGram Hashing component provides secure Bcrypt and Argon2 hashing.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/hashing
```

## Documentation

Documentation for the Hashing component can be found on the [LaraGram website](https://laraxgram.github.io/v4/hashing).
