# LaraGram Process

The LaraGram Process component provides a fluent API for invoking external processes.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/process
```

## Documentation

Documentation for the Process component can be found on the [LaraGram website](https://laraxgram.github.io/v4/processes).
