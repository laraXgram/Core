# LaraGram Config

The LaraGram Config component provides the configuration repository.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/config
```

## Documentation

Documentation for the Config component can be found on the [LaraGram website](https://laraxgram.github.io/v4/configuration).
