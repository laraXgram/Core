# LaraGram Filesystem

The LaraGram Filesystem component is a filesystem abstraction with local and cloud storage drivers.

> **Note:** This repository is a read-only split of the [LaraGram framework](https://github.com/laraxgram/core). Please send issues and pull requests to [laraxgram/core](https://github.com/laraxgram/core).

## Installation

```bash
composer require laraxgram/filesystem
```

## Documentation

Documentation for the Filesystem component can be found on the [LaraGram website](https://laraxgram.github.io/v4/filesystem).
